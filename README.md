## Description
A shoe marketplace backend thst connects buyers with shoe vendors. It allows users to explore shoe categories, place orders, manage vendors, and track payments.

##  Built With

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- Postman

## Features

- Buyer and vendor management
- Shoe category management
- Market stall management
- Shoe order management
- Receipt and payment tracking 
- Search and filtering
- Dashboard summary
- Paginated shoe orders

## Getting Started/ How to run the API

1. Clone the repository
2. Configure your database credentials in a `.env` file.
3. Run the application
4. Test the endpoints using Postman
